# Sufi Traders Website

Official website for Sufi Traders, an FMCG distribution and wholesale supplier in Daska, Punjab.

## Development

You need Node.js and npm installed to run the project locally.

```sh
git clone <this-repository-url>
cd <repository-name>
npm i
npm run dev
```

## Built with

- TanStack Start
- TypeScript
- React
- Tailwind CSS
